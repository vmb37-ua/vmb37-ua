## Featured project

### [Visualizador3D](https://github.com/vmb37-ua/Visualizador3D)
A 3D cube renderer written in pure C — every pixel drawn by hand, no graphics libraries. Projection, rotation matrices and rasterization built from the ground up.

**Status: active** — evolving into a small CLI graphics engine (simple model loading, controllable camera, character-based shading).
